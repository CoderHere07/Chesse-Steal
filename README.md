# Cheese Steal 🧀🏃

**Cheese Steal** is an intense, fast-paced first-person 3D maze game built with Unity. You play as a hungry adventurer trapped in a deadly, procedurally generated maze. Your objective is simple: navigate the labyrinth, avoid brutal dynamic traps, and find the cheese before the timer runs out! 

Can you survive the crushing walls and descending traps?

## ✨ Features
- **Procedurally Generated Mazes:** Every playthrough offers a completely unique maze layout generated at runtime using a Recursive Backtracker algorithm.
- **Dynamic Deadly Traps:** Watch your step! The maze is filled with procedurally placed traps, including:
  - **Crush Traps:** Walls that slam together to crush you.
  - **Up/Down Traps:** Spiked ceilings or floors that move unpredictably.
- **Multiple Difficulty Levels:** Choose from Easy, Medium, or Hard. The difficulty dynamically adjusts the maze size and the time limit you have to escape.
- **First-Person Controller:** Smooth, immersive first-person movement designed for quick reflexes and navigation.
- **Mini-Map Navigation:** Get lost easily? Use the mini-map to keep track of your position in the sprawling labyrinth.
- **Countdown Timer:** A relentless ticking clock keeps the pressure on. Find the cheese before time's up, or it's game over!

## 🛠️ Built With
- **Game Engine:** [Unity 6 (6000.4.3f1)](https://unity.com/)
- **Language:** C#
- **Render Pipeline:** Universal Render Pipeline (URP)

## 🚀 Getting Started

To get a local copy up and running in Unity, follow these simple steps.

### Prerequisites
- Install Unity Hub and Unity Editor version **6000.4.3f1** (or compatible Unity 6 versions).

### Installation
1. Clone the repository:
   ```sh
   git clone https://github.com/your_username/Cheese-Steal.git
   ```
2. Open **Unity Hub**.
3. Click on **Add project from disk** and select the cloned `Cheese-Steal` folder.
4. Open the project. Unity will automatically import the assets and resolve dependencies.
5. In the Project window, navigate to `Assets/Scenes` and open the main gameplay scene.
6. Press the **Play** button to start the game!

## 🎮 How to Play
- **WASD or Arrow Keys:** Move around the maze.
- **Mouse:** Look around.
- **Escape:** Pause / Main Menu.
- Navigate the corridors, avoid the moving walls and ceilings, and reach the glowing cheese collectible to win the game!
